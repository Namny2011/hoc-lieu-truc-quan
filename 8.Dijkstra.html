🎯 Bài toán Shortest Path với Dijkstra

Cho: Đồ thị vô hướng có trọng số dương gồm N đỉnh và M cạnh

Yêu cầu: Tìm đường đi ngắn nhất từ đỉnh nguồn S đến tất cả các đỉnh còn lại

🔍 Input:

  • Dòng đầu: N, M, S (số đỉnh, số cạnh, đỉnh nguồn)
  • M dòng tiếp theo: u, v, w (cạnh từ u đến v với trọng số w > 0)

📤 Output:

  • Khoảng cách từ đỉnh S đến các đỉnh 1, 2, ..., N
  • In "1000000000" nếu không có đường đi

💡 Ví dụ minh họa

📥 Input (dijkstra.inp):

5 6 1
1 2 4
1 3 2
2 3 1
2 4 5
3 4 8
3 5 10

📤 Output (dijkstra.out):

0 4 2 8 12

🔍 Giải thích:

  • Đỉnh 1 → Đỉnh 1: 0 (chính nó)
  • Đỉnh 1 → Đỉnh 2: 4 (trực tiếp)
  • Đỉnh 1 → Đỉnh 3: 2 (trực tiếp)
  • Đỉnh 1 → Đỉnh 4: 8 (1→2→4: 4+5=9 hoặc 1→3→4: 2+8=10, chọn min)
  • Đỉnh 1 → Đỉnh 5: 12 (1→3→5: 2+10=12)

🚀 Thuật toán Dijkstra

🔑 Ý tưởng chính:

d[v] = min(d[v], d[u] + weight(u,v))

📋 Trong đó:

  1. Gọi: d[u] là khoảng cách ngắn nhất từ đỉnh s đến đỉnh u
  2. Khởi tạo: d[s] = 0, d[i] = ∞ với i ≠ s
  3. Priority Queue: Chọn đỉnh u có d[u] nhỏ nhất chưa cố định
  4. Cố định: Đánh dấu u đã có đường đi ngắn nhất
  5. Cập nhật: Relaxation tất cả đỉnh kề với u

📜 Giả mã Dijkstra


Thuật toán Dijkstra(s):
    // Bước 1: Khởi tạo
    For mỗi u ∈ V:
        d[u] = +∞
    d[s] = 0

    For u thuộc  V:
        // Tìm u chưa đánh dấu tối ưu (fixed) và có d[u] nhỏ nhất
        // Cập nhật khoảng cách các đỉnh kề
        For mỗi v kề với u:
            If d[v] > d[u] + c[u][v]:
                d[v] = d[u] + c[u][v]
                truoc[v] = u   // lưu vết nếu cần
📊 Ràng buộc:
  • 🔢 1 ≤ N ≤ 10⁴ (số đỉnh)
  • 🔗 1 ≤ M ≤ 10⁶ (số cạnh)
  • ⚖️ w > 0 (trọng số cạnh dương)
  • ⚡ Độ phức tạp: O((V+E)logV)

🧠 Thuật toán Dijkstra - Phân tích chi tiết

🔍 Ý tưởng thuật toán

🎯 Nguyên lý cơ bản:

Dijkstra sử dụng Greedy Strategy - luôn chọn đỉnh có khoảng cách nhỏ nhất để xử lý.

Priority Queue: (distance, vertex)
Luôn lấy ra đỉnh có distance nhỏ nhất

🔄 Quá trình thực hiện:

  • Sử dụng Priority Queue (Min-Heap)
  • Mỗi đỉnh chỉ được "cố định" một lần
  • Khi cố định đỉnh u, d[u] đã là tối ưu
  • Chỉ cập nhật các đỉnh chưa cố định

🚨 Tại sao cần: if (du != d[u]) continue;

⚠️ Vấn đề: Priority Queue có thể chứa nhiều bản sao của cùng một đỉnh với khoảng cách khác nhau!

🔍 Ví dụ minh họa:

Bước 1: d[2] = 10, thêm (10, 2) vào PQ
Bước 2: d[2] = 5, thêm (5, 2) vào PQ
Bước 3: d[2] = 3, thêm (3, 2) vào PQ

PQ hiện tại: [(3, 2), (5, 2), (10, 2)]

Khi pop (3, 2): du = 3, d[2] = 3 ✅ OK
Khi pop (5, 2): du = 5, d[2] = 3 ❌ SKIP!
Khi pop (10, 2): du = 10, d[2] = 3 ❌ SKIP!

✅ Giải pháp:

  • du != d[u] nghĩa là khoảng cách trong PQ đã cũ
  • Bỏ qua các bản sao cũ để tránh xử lý lại
  • Chỉ xử lý khi du == d[u] (khoảng cách mới nhất)
  • Tối ưu hiệu suất: O((V+E)logV) thay vì O(VE)

🎯 Kết quả: Mỗi đỉnh chỉ được xử lý đúng 1 lần với khoảng cách tối ưu!

⚡ Phân tích độ phức tạp

🕐 Thời gian:

  • Dijkstra với Priority Queue: O((V+E)logV)
  • Dijkstra cơ bản (tìm min tuyến tính): O(V²)
  • Tốt nhất cho đồ thị thưa: O(ElogV)

💾 Không gian: O(V + E)

✅ Ưu điểm: Nhanh, chính xác với cạnh dương

❌ Nhược điểm: Không xử lý được cạnh âm

📊 So sánh với Bellman-Ford:

Dijkstra: O((V+E)logV) - Cạnh dương
Bellman-Ford: O(VE) - Cạnh âm OK

Dijkstra nhanh hơn khi: Tất cả cạnh có trọng số dương

#include <bits/stdc++.h>
// Định nghĩa kiểu dữ liệu pair<int,int> để lưu (trọng_số, đỉnh)
#define pii pair<int,int>
// Giới hạn số đỉnh tối đa
#define N 10000
// Giá trị vô cùng (1 tỷ) để biểu diễn khoảng cách ban đầu
#define inf int(1e9)
using namespace std;
// Danh sách kề: adj[u] chứa các cặp (trọng_số, đỉnh_kề)
// Ví dụ: adj[1] = {(4,2), (2,3)} nghĩa là từ đỉnh 1:
// - Đến đỉnh 2 với trọng số 4
// - Đến đỉnh 3 với trọng số 2
vector <pii> adj[N+1];

// Mảng lưu khoảng cách ngắn nhất từ đỉnh nguồn đến các đỉnh
// d[i] = khoảng cách ngắn nhất từ nguồn đến đỉnh i
// Kích thước N+2 để tránh lỗi tràn mảng
int d[N+2];

// n: số đỉnh, m: số cạnh, s: đỉnh nguồn
int n, m, s;

// Thuật toán Dijkstra với Priority Queue
void dijkstra(int s)
{
    // Priority Queue: (distance, vertex) greater<pii> để có Min-Heap
    priority_queue <pii, vector<pii>, greater <pii>> pQ;
    // Khởi tạo khoảng cách = vô cùng
    fill(d+1,d+n+1,inf);
    // Đỉnh nguồn có khoảng cách = 0
    d[s] = 0;
    pQ.push({0,s});
    while (!pQ.empty())
    {
        // Lấy đỉnh có khoảng cách nhỏ nhất
        int du = pQ.top().first;
        int u = pQ.top().second;
        pQ.pop();
        // Bỏ qua nếu đã có đường đi tốt hơn
        if (du != d[u]) continue;
        // Duyệt tất cả đỉnh kề với u
        for (auto P: adj[u])
        {
            int v = P.second;
            int w = P.first;
            // Relaxation: cập nhật nếu tìm được đường ngắn hơn
            if (d[v] > d[u] + w)
            {
                d[v] = d[u] + w;
                pQ.push({d[v],v});
            }
        }
    }
}

int main()
{
    cin >> n >> m >> s;
    // Đọc danh sách cạnh
    for (int u, v, w, i = 1; i <= m; i++)
    {
        cin >> u >> v >> w;
        adj[u].push_back({w,v});
        adj[v].push_back({w,u});
    }
    
    // Chạy thuật toán Dijkstra
    dijkstra(s);
    
    // In kết quả
    for (int i=1; i<=n; i++) cout << d[i] << " ";
    
    return 0;
}
